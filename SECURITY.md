# Sicherheit

Bitte Sicherheitslücken nicht in öffentlichen Issues offenlegen. Nutze GitHub Private Vulnerability Reporting, falls aktiviert. Die Website verarbeitet keine personenbezogenen Daten, nutzt keine Cookies und benötigt keine Secrets. Vor Veröffentlichung dürfen ausschließlich öffentliche Microsoft-Dokumentationslinks in `data/updates.json` stehen.
